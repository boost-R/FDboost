# Print and summary of a boosted functional regression model

Takes a fitted `FDboost`-object and produces a print to the console or a
summary.

## Usage

``` r
# S3 method for class 'FDboost'
summary(object, ...)

# S3 method for class 'FDboost'
print(x, ...)
```

## Arguments

- object:

  a fitted `FDboost`-object

- ...:

  currently not used

- x:

  a fitted `FDboost`-object

## Value

a list with information on the model / a list with summary information

## See also

[`FDboost`](https://boost-R.github.io/FDboost/reference/FDboost.md) for
the model fit.
